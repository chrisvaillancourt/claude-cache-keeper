# cache-keeper

A Claude Code mod (function-hook plugin) that keeps an idle session's prompt cache warm with a `$.model.fork` ping just before the TTL lapses. `README.md` is the user-facing spec; keep it in step with any behavior change in the same commit.

## Layout

- `hooks/policy.ts`: pure decisions (`decide`, `classifyPing`, `parseKeepwarmArgs`). No `$`, no I/O. Put new rules here and unit-test them in `policy.test.ts`.
- `hooks/register.ts`: wiring. Hooks (`session.start`, `turn.start`, `turn.complete`, `command.run`), the timer, the ping, logging.
- `types/index.d.ts`: types and the `$.state` contract (`PluginState['cache-keeper']`). Every `$.state` key the module uses must be declared here.
- `.claude-plugin/plugin.json`: manifest and `userConfig` options. `marketplace.json` makes the repo its own marketplace.
- `.claude-plugin/types/` and `tsconfig.json` are generated by Claude Code when the mod loads. They're gitignored; don't commit or hand-edit them.

## Commands

```sh
claude plugin validate .
claude plugin test .
```

Both must pass before every commit. Behavior changes need a test in `hooks/*.test.ts` (the `claude-code/testing` mocks drive clock, env, store and fork) that fails without the change.

## Design invariants

- **Main conversation only.** A ping replays the main thread's last request. `turn.complete` hooks return early when `e.agentId` is set, and subagents raise no `turn.start`. Never arm, reset or ping on a subagent's activity.
- **Any main-loop turn resets the idle window**, typed or not (a background agent's result, a `/loop` wakeup). That's intended, so don't filter those turns out.
- **Misses are expensive.** A fork that misses costs about a full re-cache, so a miss or a failed refresh check benches automatic pings for that Claude Code version via `$.store`. Don't weaken the bench without evidence.
- **Hot reloads reset module variables.** `register` and `session.start` run again; `$.state` and `$.store` survive. Anything that must persist goes in state or store, not in module variables.
- Skip headless sessions (`e.isInteractive === false`).
- Logging is best effort and must never throw out of a hook.

## Conventions

- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`).
- Bump `version` in `plugin.json` for a release. Installs from GitHub run a copy and only update when the version changes. An install whose marketplace is a local clone runs from the clone itself: edit, then `/reload-plugins` (`claude plugin list` shows `Read from: <clone>`). Ignore the stale copy under `~/.claude/plugins/cache/`.
- This repo is public: no secrets, tokens, session IDs, personal paths or employer-specific details in code, tests, docs or commit messages.
- Don't add Claude or AI attribution trailers to commits.
